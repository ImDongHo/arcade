플레이 방법
  • 시작하면 모든 카드를 잠깐 보여준 뒤 덮어요. 다 외웠으면 카드를 눌러 바로 시작해도 돼요.
  • 카드를 두 장씩 뒤집어 같은 그림을 찾아요. 맞히면 두 장이 빛나며 남아요.
  • 틀리면 잠깐 뒤에 다시 덮여요. 기다리지 않고 바로 다른 카드를 눌러도 돼요.
  • 시간 제한은 없어요. 몇 번 뒤집었는지는 다 찾은 뒤에만 보여주고, 크기마다 가장 적게 뒤집은 기록이 남아요.
  • 그림은 18가지 중에서 판마다 새로 골라요.
