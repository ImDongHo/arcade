플레이 방법
  • 시안색 캐릭터로 노란 상자를 밀어서, 초록 점선 자리에 모두 넣으면 클리어예요.
  • 상자는 밀 수만 있고 당길 수는 없어요. 한 번에 하나만 밀 수 있어요.
  • 스와이프하면 한 칸, 계속 밀면 계속 걸어가요. 가고 싶은 칸을 탭하면 알아서 걸어가요. PC는 방향키도 돼요.
  • 깬 스테이지엔 ✓, 최소 이동으로 깨면 은은하게 빛나요. 힌트는 불이익 없이 다음 한 걸음을 알려줘요.
  • 상자가 구석에 끼면 알려줘요. 되돌리기는 끝없이 돼요.

모든 스테이지는 다 맞춘 상태에서 거꾸로 섞어 만들어서 반드시 깰 수 있고, 최소 이동 수는 모든 경우를 따져 구했어요. 다섯 번째 판은 쉬어가는 판, 열 번째 판이 챕터의 최고점이에요.
