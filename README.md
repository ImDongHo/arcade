# arcade

직접 만들고 직접 노는 브라우저 게임 모음이에요. 설치 없이 브라우저에서 바로 플레이할 수 있어요.

| 게임 | 상태 | 설명 |
|---|---|---|
| 레이저 거울 반사 | 플레이 가능 | 거울을 돌려 빛으로 모든 타깃을 밝히는 퍼즐 (30스테이지) |
| 주차장 탈출 | 플레이 가능 | 막힌 차들을 밀어서 빨간 차를 빼내는 퍼즐 (30스테이지) |
| 네온 머지 | 플레이 가능 | 같은 숫자를 합쳐 2048까지 키우는 물리 게임 (콤보, 효과음, 이어하기) |
| 네온 버블 | 플레이 가능 | 조준해서 쏘고 같은 색 3개를 붙여 터뜨리는 버블 슈터 (끝없는 점수 도전, 이어하기) |
| 네온 스택 | 플레이 가능 | 위에서 떨어지는 블록을 타이밍 맞춰 쌓는 게임 (퍼펙트, 특수 블록, 층마다 바뀌는 하늘) |
| 색 정렬 튜브 | 플레이 가능 | 튜브를 탭해서 색 구슬을 옮겨 한 가지 색씩 맞추는 퍼즐 (30스테이지) |
| 궤도 점프 | 플레이 가능 | 행성을 도는 공을 탭 한 번으로 날려 다음 궤도에 올라타는 게임 (정확 콤보, 별, 움직이는 행성) |
| 한붓그리기 | 플레이 가능 | 모든 선을 한 번씩만 지나가게 손가락으로 그리는 퍼즐 (30스테이지) |
| 네온 2048 | 플레이 가능 | 밀어서 같은 숫자를 합치는 2048 (별 타일, 끝없는 목표, 되돌리기, 이어하기) |
| 네온 만다라 | 플레이 가능 | 손가락으로 그으면 대칭 네온 무늬가 그려지는 그림판 (사진 저장) |
| 네온 미니골프 | 플레이 가능 | 당겼다 놓아 공을 쳐서 홀에 넣는 미니골프 (8홀, 범퍼, 움직이는 벽) |
| 네온 블록 채우기 | 플레이 가능 | 조각을 끌어다 놓고 한 줄을 채워 지우는 블록 퍼즐 (콤보, 되돌리기, 이어하기) |

## 새 게임 추가하기

1. 게임 폴더를 만들고 `index.html`과 썸네일 `thumb.svg`를 넣어요.
2. `games.js`에 게임 정보를 한 줄 추가해요.

## 도구

- `tools/gen-parking.js`: 주차장 탈출 스테이지 생성기. `node tools/gen-parking.js`로 `parking-escape/levels.js`를 다시 만들어요.
- `tools/gen-color-sort.js`: 색 정렬 튜브 스테이지 생성기. `node tools/gen-color-sort.js`로 `color-sort/levels.js`를 다시 만들어요.
- `tools/gen-one-stroke.js`: 한붓그리기 스테이지 생성기. `node tools/gen-one-stroke.js`로 `one-stroke/levels.js`를 다시 만들어요.
