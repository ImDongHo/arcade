# arcade

직접 만들고 직접 노는 브라우저 게임 모음이에요. 설치 없이 브라우저에서 바로 플레이할 수 있어요.

| 게임 | 상태 | 설명 |
|---|---|---|
| 레이저 거울 반사 | 플레이 가능 | 거울을 돌려 빛으로 모든 타깃을 밝히는 퍼즐 (30스테이지) |
| 주차장 탈출 | 플레이 가능 | 막힌 차들을 밀어서 빨간 차를 빼내는 퍼즐 (30스테이지) |
| 네온 머지 | 플레이 가능 | 같은 숫자를 합쳐 2048까지 키우는 물리 게임 (콤보, 효과음, 이어하기) |
| 네온 버블 | 플레이 가능 | 조준해서 쏘고 같은 색 3개를 붙여 터뜨리는 버블 슈터 (끝없는 점수 도전, 이어하기) |

## 새 게임 추가하기

1. 게임 폴더를 만들고 `index.html`과 썸네일 `thumb.svg`를 넣어요.
2. `games.js`에 게임 정보를 한 줄 추가해요.

## 도구

- `tools/gen-parking.js`: 주차장 탈출 스테이지 생성기. `node tools/gen-parking.js`로 `parking-escape/levels.js`를 다시 만들어요.
